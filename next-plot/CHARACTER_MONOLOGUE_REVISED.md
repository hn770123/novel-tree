# （青年の独白・最終改訂）── 覗くことの仕事、手を汚す具体と罪

僕は窓をつくる人間だ。正確に言えば、重なった世界の膜に指先で裂け目を入れ、そこから流れ出す像を拾い上げる。だが、その「拾う」という動作は単に美しい光景を集める行為ではない。国家の判断材料となり、交渉戦術の素描となり、時に誰かの弱点を剥き出しにする行為でもある。

毎回の手順は決まっている。硬いリクライナーに座らされ、頭部に導電キャップが装着される。胸には心拍センサー、指先には微細動を拾うバンド。僕の身体は計測系に繋がれ、制御室のモニタに並ぶ並行像リストから、対象に近い世界線を選ぶ。僕は膜を撫でるように像を薄く引き出し、視界に景色を固定する。映像が立ち上がれば、解析者が「音声断片」「表情」「情動の波形」を記録していく。僕は見たままを口にし、重要と思われる小さな反応にフラグを立てる。それが僕の仕事だ。

僕が具体的にやってきたことを、はっきりと書く。  
・ほぼ同一の並行世界を選定し、ある要人の夢を立ち上げてその「無防備な場面」を観測した。  
・幼少期の写真や家族の話題に対する過剰反応を指摘し、報告書の注釈欄に「交渉時に触れるべき情緒的トリガー」として記した。  
・解析者の要求で、夢のディテール（寝室の匂い、枕の形、子守歌の断片）を細かく言語化してログに残し、それを封筒に入れて上席へ提出した。  
・面会許可や隔離緩和を条件に、意図的に協力度を見せるふりをして報告書に好意的な評価を書き込んだことがある。  
・逆にどうしても参加できないときは、データに「穴」を作る（視線をずらす、意図的に記録値を不安定にする）ことで小さな抵抗を試みた。  
・装置の出力映像が外部で再生される際、その映像が会議資料や交渉カードとして加工されるのを知りながら、止める術を持たなかった。

こうして取り出された「夢の断片」は、現実の交渉で強力なカードになる。僕自身が直接相手の現実を操作することはできない。だが夢で暴かれた心の拠り所やトラウマは、交渉テーブルでの説得点や揺さぶりのポイントとして現実に転用される。情報が「誰かの弱点」になり得る——その事実が、僕の中で何度も崩壊を引き起こした。

僕が見た世界の中には、筆舌に尽くしがたい光景が確かにある。医療と称する人体実験、計画的な飢えの管理、集団的な弾圧。そういう現場を、僕はただ記録した。報告書に淡々と書き連ねた。誰かを助けるための介入は、僕には許されなかった。僕は観測者であり、観測と救援は切り離されるというルールの下に動いた。見るだけで、手を差し伸べられないことの苛立ちと無力さは、夜になると胃を締め付けた。

また、能力者が普遍的に存在する並行世界では、こちらが覗かれていることを感知され、逆に拘束されかけたことがある。そこで僕は、覗く側が一瞬で被観測側に転じる危険を知った。あのときの恐怖は今も抜けない。運良く逃げ延びたが、能力の有用性は同時に致命的なリスクを孕むことを理解した。

組織は冷徹に、そのリスクと利益を秤にかけた。装置を作り、観測像を可視化して出力し、研究部門や交渉部門に配った。僕が指摘した「この句に反応した」「この写真に動揺した」といった注釈が、外交文書のひと節になり、交渉戦術の一部になった。代表はいつも言う——「情報は使われる。使わないことがリスクだ」と。理屈としては正しい。だが理屈が正しいからといって、それが倫理的に正当化されるわけではない。

僕は嘘をついたこともある。面会許可を取り戻すために、報告を甘く書いた夜。嘘をついた自分は、その後もずっと赦せなかった。データに「穴」を作ったときは、技術者の眉間に皺を寄せられ、しかし表向きは「ノイズ」で片付けられた。小さな抵抗は意味を持つが、根本を変えられるものではなかった。

一方で、覗くことによる純粋な喜びも隠せない。ある世界の小さな窓で、古い男が路地で詩を口ずさんでいるのを見つけたとき、僕は胸が震えた。別の世界で、科学者が真夜中に残した走り書きが僕の目に飛び込み、そこからひらめきが生まれることもあった。そういう瞬間は、本当に僕を人間に戻す。だからまた窓を開けてしまう自分がいる。

だがもっと深刻なのは、夢で得た情報が「人の脆さ」を洗い出すことであり、それを交渉材料に変える行為が、人として許されるかどうかだ。僕はそれを「仕事」と割り切れない。僕は誰かの幼年期の傷を、計算式に差し替える手伝いをしたのだ。そう思うと、夜が長くなる。

最後に一つだけ確かなことを言おう。僕は自分で枠を引いた。組織に与えられた最後ではなく、自分で「今回が最後だ」と決めた。だがそれは簡単な決断ではない。君の顔を夢で見ると、僕の胸の中の何かが軽くなる。君の無防備な呼吸が、どうしても僕を引き寄せる。僕はその事実を恥じる。許しを乞うつもりはない。ただ、愚かさを告白する。僕は見てしまう。見てしまった後で、自分が何をしてしまったのかを知る——その繰り返しだ。
